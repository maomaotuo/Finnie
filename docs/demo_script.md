# Suggested 5–10 minute capstone demo

1. **Introduction (45 seconds).** Explain Finnie's beginner financial education use case. Identify the six agents, LangGraph supervisor, and RAG, and distinguish education from personalized advice.
2. **Grounded conversation (90 seconds).** Ask “What is an ETF?” and “How does it differ from a mutual fund?” Show citations, specialist label, and preserved context. Explain that retrieved documents support answers.
3. **Portfolio (90 seconds).** Load the illustrative sample. Show $8,500 total supplied value, holding allocation, asset allocation, and concentration limitations. Add fund expense ratio data if demonstrating fees. In Chat select Portfolio and ask about concentration.
4. **Market (60 seconds).** Look up AAPL over one month, switch to one day, and show source and timestamps. Explain delay and cache behavior. Do not describe a cached quote as a live exchange tick.
5. **Goals (90 seconds).** Calculate the default goal, compare projected savings with required contributions, and explain assumptions. Change risk appetite and assumed return deliberately; clarify that risk appetite does not guarantee a return. Select Goal in chat and ask about the saved plan.
6. **Advanced agents (60 seconds).** With a ticker selected, request recent news and show linked headlines. Select Tax and ask an educational capital-gains question; mention jurisdiction and tax-year limitations.
7. **Engineering evidence (60 seconds).** Show the architecture and passing tests, session isolation, Python calculations, market outage handling, and README launch steps.
8. **Close (30 seconds).** Show an MCP client discovering Finnie’s tools and calling the savings calculator. Mention future authentication and deployment work.

Before recording, confirm live model and market access, cache the embedding model, and use sample financial information. Record the app window and selected terminal evidence. A demo video is a user-produced submission artifact and is not generated by the automated test suite.
